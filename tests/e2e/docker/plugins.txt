# Plugins baked into the end-to-end Jenkins image, with versions pinned.
#
# Pinning the base image digest is not enough on its own: jenkins-plugin-cli
# resolves latest-compatible by default, so the same Dockerfile would quietly
# produce a different Jenkins next month. Silent version drift is the class of
# bug this suite exists to catch, so it must not be in the suite itself.
#
# Keep this list minimal — every plugin is boot time, and boot time is paid
# once per test session.
#
# To refresh: check https://updates.jenkins.io/current/update-center.actual.json
# and confirm each plugin's requiredCore is satisfied by the image in the
# Dockerfile. Verified against core 2.580.1.
